# JHJ AI Usage Monitor — 배포판

**JHJ AI 통합 사용량 모니터**는 Claude Code · Codex 의 세션 · 주간 한도와 일별 비용을 트레이 팝업으로 보여 주는 Windows 앱입니다.

## 받기

**JHJ 포털에서 받습니다** — https://jhj.wecco.co.kr/download/#ai-usage

- JHJ 계정으로 로그인하면 바로 받습니다.
- 로그인하지 않으면 메일로 기한이 있는 다운로드 주소를 보내 드립니다.
- 메일로 받은 주소는 누르는 순간의 최신 판을 JHJ 서버에서 내려받는 기한부 주소입니다.

이미 설치한 앱은 스스로 업데이트합니다. 업데이트 파일은 JHJ 서버에서 받고, 받을 때마다 원본과 같은지(SHA-256) 확인합니다.

## 이 저장소

- 판마다 무엇이 추가 · 개선 · 수정됐는지 [Releases](https://github.com/HyungJIn-kr-97/JHJ_AI_USAGE_RELEASE/releases) 에 남깁니다.
- 소스 코드는 비공개 저장소에 있고 여기에는 올리지 않습니다.
- 배포 방식을 옮기는 동안에는 이미 설치된 옛 판의 업데이트를 위해 Releases 에 설치 파일도 함께 올라갑니다. 새로 받을 때는 위의 포털을 이용해 주십시오.

## 참고

- Windows 10/11 x64 전용입니다.
- 코드 서명이 없어 처음 실행할 때 SmartScreen 창이 뜰 수 있습니다. 「추가 정보」 → 「실행」을 누릅니다.

## 수집하는 사용 정보

설치 관리자에서 **사용 정보 수집 동의**에 체크해야 「설치」가 눌립니다. 모은 정보는 **어디로도 자동 전송되지 않습니다** — 설정 › 일반 「진단 정보」의 「복사」 · 「파일로 저장」으로 사용자가 직접 꺼내 [이슈](https://github.com/HyungJIn-kr-97/JHJ_AI_USAGE_RELEASE/issues/new)에 붙입니다.

| 모으는 것 | 쓰임 |
|---|---|
| 앱 버전 · Windows 버전 · .NET · 언어 | 장비마다 다른 동작 재현 |
| 설정값(갱신 주기 · 계정 명칭 · 유형 · 요금 · 프로그램 연동표 · 등급 경계) | 설정 조합에 따른 차이 |
| Claude 자리마다 — 로그인 계정 UUID(앞 8자) · 자격 파일 유무 · 플랜 · 등급 · 만료 · 로그 파일 수 · 용량 · 기간 | 「계정 연동이 안 잡힌다」 「사용량이 비었다」 원인 |
| 프로그램 라우팅 표 · 세션 메타 수 · 에이전트 모드 폴더 | 「어느 프로그램이 어느 계정으로 세졌나」 근거 |
| 이력 파일별 건수 · 기간 · 비용 · 토큰 합계 | 사용량 차트 · 활용도 계산 검증 |
| 마지막 갱신 상태(계정별 신뢰도 · 출처 · 상태 문구 · 한도 · 비용) · 이벤트 로그 최근 200줄 | 오류 추적 |

**가리는 것** — 메일은 첫 글자+도메인, UUID 는 앞 8자, 경로의 사용자 폴더는 `%USERPROFILE%`. **넣지 않는 것** — 토큰 · 대화 내용 · 프로젝트 경로.
